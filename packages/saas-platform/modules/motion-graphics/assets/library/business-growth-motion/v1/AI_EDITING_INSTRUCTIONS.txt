Asset: business-growth-motion v1 (Business Growth Motion)

Allowed edits:
- Colors: change only the --asset-* values in <style id="asset-theme">, in both the light :root block and the prefers-color-scheme:dark block.
- Text: Persian copy inside <text> elements; keep Persian digits and right-to-left reading order.
- Speed: animation durations and delays in the second <style> block.

Forbidden:
- <script>, event handler attributes (on*), <foreignObject>, external href/src, web fonts, SMIL <animate*> elements.
- Animating layout or filter properties; animate transform/opacity only.
- Removing the @media (prefers-reduced-motion:reduce) rule or the viewBox.
- Editing a published version in place: create a new version directory instead.
