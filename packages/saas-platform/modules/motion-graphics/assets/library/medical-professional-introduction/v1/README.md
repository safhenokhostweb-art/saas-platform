# معرفی حرفه‌ای پزشک

معرفی پزشک، خدمات درمانی، ارتباط با بیمار و شاخص‌های اعتماد در یک صحنه حرفه‌ای.

## کاربردها

- پزشکان، درمانگاه‌ها، کلینیک‌ها و بیمارستان‌ها
- Hero صفحه اصلی
- بخش درباره ما و خدمات
- لندینگ تخصصی

## مشخصات

- SVG + CSS + SMIL
- viewBox برابر 960×540 و responsive
- پس‌زمینه animation.svg شفاف
- بدون script، dependency، URL یا فونت خارجی
- title، desc، role و aria-labelledby
- prefers-reduced-motion
- حجم animation.svg: 5,575 بایت (حدود 5.4KB)
