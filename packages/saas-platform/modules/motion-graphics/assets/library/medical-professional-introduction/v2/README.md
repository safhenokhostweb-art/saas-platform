# معرفی حرفه‌ای پزشک — v2

بازطراحی مستقل با روایت «پزشک و بیمار در دو سوی یک پنل سلامت با موج قلب و گفت‌وگوی امن.»

## تفاوت با v1

v1 از شبکه عمومی استفاده می‌کرد. v2 بر سبک doctor-patient consultation scene و عناصر doctor portrait، patient portrait، heart waveform، digital health panel، secure consultation تکیه دارد.

## مشخصات

- SVG + CSS + SMIL
- 960×540 responsive و پس‌زمینه شفاف
- بدون dependency، script، URL و فونت خارجی
- prefers-reduced-motion و دسترس‌پذیری کامل
- حجم animation.svg: 4,253 بایت (حدود 4.2KB)
