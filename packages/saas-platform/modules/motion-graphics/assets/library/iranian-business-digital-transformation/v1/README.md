# تحول دیجیتال کسب‌وکار ایرانی

حرکت یک کسب‌وکار سنتی ایرانی به سوی زیرساخت ابری، داده، هوش مصنوعی و رشد دیجیتال.

## کاربردها

- شرکت‌های فناوری، پلتفرم‌های SaaS و مشاوران تحول دیجیتال
- Hero صفحه اصلی
- بخش درباره ما و خدمات
- لندینگ تخصصی

## مشخصات فنی

- SVG + CSS + SMIL
- viewBox برابر 960×540 و responsive
- پس‌زمینه animation.svg شفاف
- بدون script، dependency، URL یا فونت خارجی
- دسترس‌پذیر با title، desc، role و aria-labelledby
- پشتیبانی از prefers-reduced-motion
- حجم animation.svg: 5,586 بایت (حدود 5.5KB)
