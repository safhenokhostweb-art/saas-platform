# تحول دیجیتال کسب‌وکار ایرانی — v2

بازطراحی مستقل با روایت «فرایند سنتی در سمت چپ وارد لایه‌های تبدیل می‌شود و به داشبورد ابری و رشد دیجیتال در سمت راست می‌رسد.»

## تفاوت با v1

v1 از ترکیب عمومی گره‌ها و خطوط استفاده می‌کرد. v2 از سبک left-to-right transformation pipeline و عناصر اختصاصی traditional office، transformation layers، cloud platform، automation gears، digital growth chart استفاده می‌کند.

## کاربرد

Homepage hero، About section و Services section برای Technology.
