# شبکه کسب‌وکارهای ایران

نمایش نقشه ایران با گره‌های تجاری و ارتباطات دیجیتال میان کسب‌وکارها در سراسر کشور.

## کاربردها

- وب‌سایت شرکت‌ها و لندینگ‌های SaaS
- Hero صفحه اصلی
- بخش درباره ما و خدمات
- لندینگ تخصصی

## مشخصات

- SVG + CSS + SMIL
- viewBox برابر 960×540 و responsive
- پس‌زمینه animation.svg شفاف
- بدون script، dependency، URL یا فونت خارجی
- title، desc، role و aria-labelledby
- prefers-reduced-motion
- حجم animation.svg: 5,667 بایت (حدود 5.5KB)
