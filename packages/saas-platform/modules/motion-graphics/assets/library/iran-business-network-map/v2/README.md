# شبکه کسب‌وکارهای ایران — v2

بازطراحی با نقشه قابل‌شناسایی و هندسه استان‌های ایران، مبدأ قزوین و مسیرهای توسعه بازار.

## تفاوت با v1

v1 یک نماد کوچک و ساده از ایران داشت. v2 از هندسه دقیق استان‌ها، موقعیت‌های واقعی شهرها و روایت توسعه بازار منطقه‌ای استفاده می‌کند.

## مشخصات

- SVG + CSS + SMIL
- 960×540 responsive و پس‌زمینه شفاف
- هندسه استان‌ها به‌صورت داخلی embed شده و بدون dependency است
- بدون script، URL و فونت خارجی
- prefers-reduced-motion و دسترس‌پذیری کامل
- حجم animation.svg: 55,450 بایت (حدود 54.2KB)
