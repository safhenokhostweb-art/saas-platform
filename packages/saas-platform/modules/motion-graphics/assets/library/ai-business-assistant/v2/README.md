# دستیار هوشمند کسب‌وکار — v2

بازطراحی مستقل با روایت «یک هسته مغزی AI در کنار داشبورد زنده، کارت پیشنهاد و صف وظایف خودکار.»

## تفاوت با v1

v1 از ترکیب عمومی گره‌ها و خطوط استفاده می‌کرد. v2 از سبک assistant workspace with scanning and recommendations و عناصر اختصاصی AI brain core، analysis dashboard، recommendation card، automated checklist، live scanner استفاده می‌کند.

## کاربرد

Homepage hero، About section و Services section برای AI.
