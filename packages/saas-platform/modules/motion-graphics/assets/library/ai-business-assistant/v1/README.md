# دستیار هوشمند کسب‌وکار

نمایش هسته هوش مصنوعی که داشبورد، اتوماسیون، پیشنهادهای هوشمند و سرویس‌های کسب‌وکار را هماهنگ می‌کند.

## کاربردها

- شرکت‌های هوش مصنوعی، نرم‌افزاری و استارتاپ‌های مدرن
- Hero صفحه اصلی
- بخش درباره ما و خدمات
- لندینگ تخصصی

## مشخصات فنی

- SVG + CSS + SMIL
- viewBox برابر 960×540 و responsive
- پس‌زمینه animation.svg شفاف
- بدون script، dependency، URL یا فونت خارجی
- دسترس‌پذیر با title، desc، role و aria-labelledby
- پشتیبانی از prefers-reduced-motion
- حجم animation.svg: 5,717 بایت (حدود 5.6KB)
