# Construction Barrier

دارایی SVG سبک و مستقل از مجموعه ساخت‌وساز، مناسب قالب‌های وب، Hero، کارت محصول، داشبورد و موشن‌گرافیک.

## Theme API

- `--asset-primary`
- `--asset-secondary`
- `--asset-accent`
- `--asset-background`
- `--asset-border`
- `currentColor` برای جزئیات خطی

## استفاده

```html
<img src="/assets/visual-assets/object-library/construction/construction-barrier/asset.svg" alt="Construction Barrier">
```

برای کنترل مستقیم متغیرهای CSS، SVG پاک‌سازی‌شده را inline کنید. asset.svg شفاف و preview.svg دارای پس‌زمینه تم‌پذیر است. فایل هیچ script، فونت یا URL خارجی ندارد.
