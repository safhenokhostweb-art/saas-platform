# کارت ویزیت

کارت‌های ویزیت لایه‌ای با محل لوگوی قابل ویرایش.

## کاربردها

Hero، پس‌زمینه، معرفی محصول و بخش‌های محتوایی وب‌سایت‌های ایرانی.

## مشخصات فنی

- فرمت: SVG
- نوع: object
- viewBox: 0 0 800 600
- پس‌زمینه asset.svg: شفاف
- وابستگی خارجی: ندارد
- اسکریپت و فونت خارجی: ندارد
- مقیاس‌پذیر و مناسب نمایشگرهای Retina

## استفاده

```html
<img src="/assets/visual-assets/business-objects/business-cards/asset.svg" alt="کارت ویزیت" width="800" height="600">
```

## شخصی‌سازی

رنگ‌های پایه با متغیرهای CSS داخلی کنترل می‌شوند. برای تغییر مستقیم متغیرها، SVG را پس از پاک‌سازی امنیتی به‌صورت inline استفاده کنید. preview.svg فقط یک نمای نمونه با پس‌زمینه تیره است.
