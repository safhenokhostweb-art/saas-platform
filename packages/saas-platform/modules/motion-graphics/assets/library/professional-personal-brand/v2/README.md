# برند شخصی حرفه‌ای — v2

بازطراحی مستقل با روایت «پروفایل متخصص در کنار یک تایم‌لاین عمودی از مهارت، تجربه، دستاورد و ارتباط.»

## تفاوت با v1

v1 از ترکیب عمومی گره‌ها و خطوط استفاده می‌کرد. v2 از سبک vertical professional timeline و عناصر اختصاصی expert portrait، skill badges، experience timeline، achievement medal، communication card استفاده می‌کند.

## کاربرد

Homepage hero، About section و Services section برای Personal Brand.

## مشخصات

- SVG + CSS + SMIL
- 960×540 responsive
- animation.svg با پس‌زمینه شفاف
- بدون dependency، script، URL و فونت خارجی
- prefers-reduced-motion
- title، desc، role و aria-labelledby
- حجم animation.svg: 4,747 بایت (حدود 4.6KB)
