# نمایش خدمات ساخت‌وساز — v2

بازطراحی مستقل با روایت «نقشه blueprint روی میز به کمک جرثقیل و فرایند مهندسی به ساختمان واقعی تبدیل می‌شود.»

## تفاوت با v1

v1 از شبکه عمومی استفاده می‌کرد. v2 بر سبک blueprint-to-building construction sequence و عناصر blueprint grid، architecture drawing، tower crane، rising floors، location marker تکیه دارد.

## مشخصات

- SVG + CSS + SMIL
- 960×540 responsive و پس‌زمینه شفاف
- بدون dependency، script، URL و فونت خارجی
- prefers-reduced-motion و دسترس‌پذیری کامل
- حجم animation.svg: 5,085 بایت (حدود 5KB)
