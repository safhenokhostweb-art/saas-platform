# نمایش خدمات ساخت‌وساز

نمایش معماری، ساختمان، پروژه‌ها، موقعیت مکانی و رشد یک کسب‌وکار ساخت‌وساز.

## کاربردها

- شرکت‌های ساختمانی، مهندسان معماری و آژانس‌های املاک
- Hero صفحه اصلی
- بخش درباره ما و خدمات
- لندینگ تخصصی

## مشخصات

- SVG + CSS + SMIL
- viewBox برابر 960×540 و responsive
- پس‌زمینه animation.svg شفاف
- بدون script، dependency، URL یا فونت خارجی
- title، desc، role و aria-labelledby
- prefers-reduced-motion
- حجم animation.svg: 5,524 بایت (حدود 5.4KB)
