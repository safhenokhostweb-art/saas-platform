# سفر مشتری فروشگاه اینترنتی — v2

بازطراحی مستقل با روایت «یک مسیر خرید پیوسته با پنج ایستگاه مستقل و حرکت سبد خرید روی مسیر.»

## تفاوت با v1

v1 از ترکیب عمومی گره‌ها و خطوط استفاده می‌کرد. v2 از سبک sequential customer journey و عناصر اختصاصی product card، moving cart، secure payment، delivery truck، happy customer استفاده می‌کند.

## کاربرد

Homepage hero، About section و Services section برای E-commerce.

## مشخصات

- SVG + CSS + SMIL
- 960×540 responsive
- animation.svg با پس‌زمینه شفاف
- بدون dependency، script، URL و فونت خارجی
- prefers-reduced-motion
- title، desc، role و aria-labelledby
- حجم animation.svg: 4,891 بایت (حدود 4.8KB)
