# سفر مشتری فروشگاه اینترنتی

مسیر کامل خرید آنلاین از کشف محصول تا سبد خرید، پرداخت امن، ارسال و رضایت مشتری.

## کاربردها

- فروشگاه‌های اینترنتی و مارکت‌پلیس‌ها
- Hero صفحه اصلی
- بخش درباره ما و خدمات
- لندینگ تخصصی

## مشخصات فنی

- SVG + CSS + SMIL
- viewBox برابر 960×540 و responsive
- پس‌زمینه animation.svg شفاف
- بدون script، dependency، URL یا فونت خارجی
- دسترس‌پذیر با title، desc، role و aria-labelledby
- پشتیبانی از prefers-reduced-motion
- حجم animation.svg: 5,587 بایت (حدود 5.5KB)
