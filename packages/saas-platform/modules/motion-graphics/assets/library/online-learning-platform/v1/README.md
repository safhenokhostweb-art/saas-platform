# آموزش و یادگیری آنلاین

نمایش مدرس، دانش‌پذیران، دوره‌های آنلاین و جریان اشتراک دانش در یک پلتفرم آموزشی.

## کاربردها

- مدارس، آموزشگاه‌ها، شرکت‌های آموزشی و مربیان
- Hero صفحه اصلی
- بخش درباره ما و خدمات
- لندینگ تخصصی

## مشخصات

- SVG + CSS + SMIL
- viewBox برابر 960×540 و responsive
- پس‌زمینه animation.svg شفاف
- بدون script، dependency، URL یا فونت خارجی
- title، desc، role و aria-labelledby
- prefers-reduced-motion
- حجم animation.svg: 5,583 بایت (حدود 5.5KB)
