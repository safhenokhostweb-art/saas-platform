# آموزش و یادگیری آنلاین — v2

بازطراحی مستقل با روایت «دانش از کتاب باز وارد کلاس آنلاین می‌شود و در قالب دوره و پیشرفت دانش‌پذیر ادامه می‌یابد.»

## تفاوت با v1

v1 از شبکه عمومی استفاده می‌کرد. v2 بر سبک knowledge unfolding into a digital classroom و عناصر open book، teacher screen، course cards، student workspace، progress ribbon تکیه دارد.

## مشخصات

- SVG + CSS + SMIL
- 960×540 responsive و پس‌زمینه شفاف
- بدون dependency، script، URL و فونت خارجی
- prefers-reduced-motion و دسترس‌پذیری کامل
- حجم animation.svg: 5,024 بایت (حدود 4.9KB)
