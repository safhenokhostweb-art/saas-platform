# معرفی حرفه‌ای شرکت ایرانی

یک دارایی SVG سبک برای معرفی هویت، تیم، خدمات، محصولات، مشتریان و مسیر رشد شرکت‌های ایرانی. طراحی برای Hero و sectionهای شرکتی انجام شده و برای شرکت‌های تولیدی، خدماتی، صنعتی، مهندسی و فناوری قابل شخصی‌سازی است.

## موارد استفاده

- Hero صفحه اصلی شرکت
- بخش درباره ما
- معرفی خدمات و توانمندی‌ها
- لندینگ شرکتی یا صنعتی
- معرفی تیم و اعتماد مشتریان

## مشخصات فنی

- فناوری: SVG + CSS + SMIL
- ابعاد منطقی: 960×540 با viewBox responsive
- پس‌زمینه animation.svg: شفاف
- وابستگی، فونت و URL خارجی: ندارد
- حرکت کاهش‌یافته: پشتیبانی از prefers-reduced-motion
- دسترس‌پذیری: title، desc، role و متن جایگزین پیشنهادی
- حجم animation.svg: 7,423 بایت (حدود 7.2KB)

در Laravel، پس از انتشار توسط کتابخانه آینده، دارایی باید از manifest نسخه منتشرشده مصرف شود. فایل source نباید مستقیماً به tenant ارائه شود.

## سازگاری مرورگر

برای مرورگرهای مدرن دسکتاپ و موبایل طراحی شده است. اگر SMIL در یک WebView محدود اجرا نشود، ساختار کامل SVG همچنان به شکل ثابت و خوانا نمایش داده می‌شود. حالت reduced motion تمام animationهای CSS را متوقف و نمودار را در وضعیت کامل نشان می‌دهد.

## شخصی‌سازی

رنگ‌ها و سرعت با CSS variableهای ابتدای animation.svg کنترل می‌شوند. برای تغییر لوگو یا ساختار عناصر، SVG باید در فرایند authoring و به‌صورت نسخه جدید ویرایش و sanitize شود.
