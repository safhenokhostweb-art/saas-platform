# صنعت و تولید ایران — v2

بازطراحی مستقل با روایت «یک خط تولید فعال از کارخانه تا مونتاژ، اسکن کیفیت و خروج محصول.»

## تفاوت با v1

v1 از ترکیب عمومی گره‌ها و خطوط استفاده می‌کرد. v2 از سبک mechanical production line و عناصر اختصاصی factory hall، conveyor belt، rotating gear، robotic press، quality scanner استفاده می‌کند.

## کاربرد

Homepage hero، About section و Services section برای Industry.
