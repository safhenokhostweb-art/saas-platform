# صنعت و تولید ایران

نمایش کارخانه، خط تولید، مهندسی، کنترل کیفیت، محصول و توسعه بازار.

## کاربردها

- تولیدکنندگان و شرکت‌های صنعتی و مهندسی
- Hero صفحه اصلی
- بخش درباره ما و خدمات
- لندینگ تخصصی

## مشخصات فنی

- SVG + CSS + SMIL
- viewBox برابر 960×540 و responsive
- پس‌زمینه animation.svg شفاف
- بدون script، dependency، URL یا فونت خارجی
- دسترس‌پذیر با title، desc، role و aria-labelledby
- پشتیبانی از prefers-reduced-motion
- حجم animation.svg: 5,533 بایت (حدود 5.4KB)
