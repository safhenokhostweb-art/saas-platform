# Motion Creation Assistant Playground

Dependency-free local prototype of the guided wizard, deterministic Motion Planner, real-time quality warnings, mock multilingual font analysis, optional voice planning, quality scoring, and Beginner/Expert presentation modes.

```bash
npm test --prefix tools/motion-creation-assistant-playground
npm run serve --prefix tools/motion-creation-assistant-playground
```

Open `http://127.0.0.1:4175/tools/motion-creation-assistant-playground/`.

No backend, API, provider, asset generation, font conversion, audio generation, publication, or runtime integration exists. All results are local proposals.
