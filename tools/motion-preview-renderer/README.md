# Motion Preview Renderer

Dependency-free, read-only preview engine consuming existing Motion Plan and Asset Library contracts.

```bash
npm test --prefix tools/motion-preview-renderer
npm run report --prefix tools/motion-preview-renderer
npm run serve --prefix tools/motion-preview-renderer
```

Open `http://127.0.0.1:4176/tools/motion-preview-renderer/`. No export, backend, Laravel, database, AI, asset generation, publication, or production deployment exists.
