## Architecture Overview

```
PlatformInstallerController::processFreshFinish()
    │
    ├─ [1] InstallationReportService::collect()
    │        → Generates installation_id (UUID), health scores, system info
    │
    ├─ [2] UpgradeAdapter::createInstallationBaseline($uuid)
    │        → BaselineManifestService::resolveBaselineName()  (immutable naming)
    │        → snapshotDatabase() → database.sql.gz
    │        → snapshotEnv()      → .env.backup
    │        → write baseline_meta.json
    │        → BaselineManifestService::createManifest()       (SHA-256 × 3 files)
    │        → Returns: baseline_path, manifest_checksum
    │
    ├─ [3] InstallationReportService::enrichWithBaseline()
    │        → BaselineManifestService::verify()               (full integrity check)
    │        → Computes overall_status (PASS/WARNING/FAILED)
    │        → Sets installation_certification text
    │
    ├─ [4] InstallationReportService::generateHtml()
    │        → Renders with baseline sections, manifest checksum, overall status
    │
    ├─ [5] InstallationReportService::generatePdf()
    │
    └─ [6] UpgradeAdapter::addReportsToBaseline()
             → Copies HTML/PDF into baseline
             → BaselineManifestService::updateManifest()       (SHA-256 × 5 files)
             → BaselineManifestService::makeReadOnly()         (0444/0555)
```
