# SEO Advanced — Admin Guide

این راهنما برای مدیر پلتفرم (یا مدیر سایت مشتری) است که از پنل مدیریت ماژول در آدرس `/admin/seo-advanced/{siteId}` استفاده می‌کند.

## داشبورد (`/admin/seo-advanced/{siteId}`)

نمای کلی: عنوان متا فعلی، دستورالعمل Robots، تعداد ریدایرکت‌ها، آخرین امتیاز SEO، و وضعیت فنی (Robots/Schema/Sitemap تنظیم شده‌اند یا نه).

## تنظیمات SEO (`/admin/seo-advanced/{siteId}/meta`)

### Meta Management
- عنوان، توضیحات، کلمات کلیدی متا
- **Robots**: `index,follow` / `noindex,follow` / `index,nofollow` / `noindex,nofollow`
- **Canonical URL** + **سیاست Canonical (Canonical Policy)**:
  - `auto`: آدرس همان صفحه استفاده می‌شود (پیش‌فرض توصیه‌شده).
  - `force_https`: هر Canonical محاسبه‌شده به‌اجبار به https تبدیل می‌شود.
  - `custom`: دقیقاً همان Canonical URL که در بالا وارد کرده‌اید، صرف‌نظر از صفحه.
- **آستانه طول عنوان/توضیحات**: قابل تنظیم دستی (پیش‌فرض: عنوان ۳۰-۶۰ کاراکتر، توضیحات ۷۰-۱۶۰ کاراکتر) — این مقادیر مستقیماً روی نتیجه Audit Engine اثر می‌گذارند.

### OpenGraph / Twitter Card
مقادیر پیش‌فرض OG (در صورت نبود override در سطح صفحه استفاده می‌شود) + نوع Twitter Card (`summary` یا `summary_large_image`).

### Schema.org
نوع (`Organization` / `LocalBusiness` / `WebSite`) + فیلدهای مرتبط.

## ریدایرکت‌ها (`/admin/seo-advanced/{siteId}/redirects`)

افزودن/ویرایش/حذف ریدایرکت 301 یا 302. این ریدایرکت‌ها واقعاً روی هر درخواست GET سایت اجرا می‌شوند (از طریق Middleware سراسری این ماژول)، نه فقط یک لیست ثبت‌شده در دیتابیس.

## ارزیابی SEO / Audit (`/admin/seo-advanced/{siteId}/audit`)

فرم ارزیابی یک صفحه را می‌پذیرد:
- آدرس صفحه، عنوان، توضیحات، H1، Canonical (الزامی برای بررسی حداقلی)
- **ساختار تیترها (اختیاری)**: هر خط به‌فرمت `سطح|متن`، مثال:
  ```
  1|عنوان اصلی صفحه
  2|زیرعنوان اول
  ```
  این ورودی برای بررسی سلسله‌مراتب تیترها (دقیقاً یک H1، بدون پرش سطح) استفاده می‌شود.
- **OG Title/Description/Image (اختیاری)**: برای بررسی کامل بودن OpenGraph صفحه.
- **بررسی ساختار آدرس (اختیاری)**: چک‌باکس — در صورت فعال بودن، حروف بزرگ/زیرخط/فاصله/طول بیش‌ازحد آدرس بررسی می‌شود.

نتیجه هر ارزیابی شامل: امتیاز (۰ تا ۱۰۰)، و فهرست مشکلات با severity (`critical` / `warning` / `recommendation`)، پیام، و راه‌حل پیشنهادی (`suggested_fix`) است.

## پیگیری کلمات کلیدی (`/admin/seo-advanced/{siteId}/keywords`)

ثبت کلمه کلیدی + آدرس هدف + وضعیت (فعال/متوقف‌شده/بایگانی‌شده). رتبه فعلی را می‌توان دستی وارد کرد؛ هر بار ثبت رتبه به تاریخچه (`position_history`) اضافه می‌شود. **این بخش به هیچ سرویس بیرونی رتبه‌سنجی متصل نیست** — صرفاً یک زیرساخت ساده برای ثبت و نمایش است.

## گزارش SEO (`/admin/seo-advanced/{siteId}/report`)

خلاصه وضعیت کلی سایت: آخرین امتیاز، تعداد مشکلات به تفکیک severity، تعداد صفحات ارزیابی‌شده، روند امتیاز در طول زمان، و فهرست کلمات کلیدی با رتبه فعلی.
