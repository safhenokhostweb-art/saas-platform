# راهنمای راه‌اندازی سایت مشتری روی هاست دیگر

---

## تنظیمات ویژهٔ سایت مالک (سایت پیشخوان شما)

اگر سایت شما روی دامنهٔ اصلی (مثلاً safhenokhost.ir) است و لینک بانک روی آن فعال است:

### پلتفرم (panel.safhenokhost.ir) — `.env`
```
PAYMENT_CALLBACK_URL=https://safhenokhost.ir
```
با این تنظیم، بانک کاربر را به safhenokhost.ir برمی‌گرداند و سایت شما آن را به پنل فوروارد می‌کند.

### سایت مالک (safhenokhost.ir) — `.env`
```
OWNER_SITE=true
PLATFORM_URL=https://panel.safhenokhost.ir
```

### صفحهٔ محصولات پلتفرم
- آدرس: `https://safhenokhost.ir/platform-products`
- محصولات (لایسنس، ماژول، پشتیبانی) از API پلتفرم دریافت و نمایش داده می‌شوند.
- دکمهٔ «خرید» به پنل با پیش‌پر سبد لینک می‌دهد.

---

وقتی یک مشتری جدید سایت می‌خواهد خریداری کند، مراحل زیر را طی کنید.

---

## مرحله ۱: در پنل saas-platform (پنل شما)

### ۱.۱ ثبت مشتری
- **مسیر:** مشتری‌ها → افزودن مشتری
- نام، شرکت، ایمیل، موبایل و یادداشت را وارد کنید.

### ۱.۲ ایجاد سایت برای مشتری
- **مسیر:** سایت‌ها → افزودن سایت
- **فیلدها:**
  - مشتری: انتخاب مشتری ثبت‌شده
  - عنوان: نام سایت (مثلاً «سایت شرکت الف»)
  - دامنه: دامنهٔ واقعی سایت مشتری (مثلاً `shop.example.ir`) — **مهم برای لایسنس**
  - ماژول‌ها: blog، shop و سایر ماژول‌های موردنیاز را انتخاب کنید
  - تاریخ انقضای پشتیبانی (اختیاری)
  - وضعیت: فعال

### ۱.۳ صدور لایسنس
- **مسیر:** سایت‌ها → انتخاب سایت → لایسنس → صدور لایسنس
- دامنهٔ مجاز را وارد کنید (یا خالی بگذارید برای هر دامنه)
- تاریخ انقضا (اختیاری)
- **کلید لایسنس فقط یک‌بار نمایش داده می‌شود** — آن را کپی کرده و به مشتری تحویل دهید.

---

## مرحله ۲: آماده‌سازی پروژه customer-site برای مشتری

### ۲.۱ کپی پروژه
- کل پروژه **customer-site** را کپی کنید (یا از Git clone بگیرید).
- این کپی همان کدی است که روی هاست مشتری آپلود می‌شود.

### ۲.۲ فایل‌های حذف/تغییر قبل از تحویل
- فایل `.env` را حذف کنید (یا از `.env.example` استفاده کنید).
- فایل `storage/installed.lock` را حذف کنید تا ویزارد نصب اجرا شود.
- در `.env.example` مقدار `PLATFORM_URL` را به آدرس پلتفرم خود تنظیم کنید (مثلاً `https://panel.example.com`).

---

## مرحله ۳: آپلود روی هاست مشتری

### ۳.۱ نیازمندی‌های سرور
- PHP 8.2+
- MySQL یا MariaDB
- Composer
- دسترسی به ترمینال (SSH) برای اجرای دستورات

### ۳.۲ مراحل آپلود
1. فایل‌های پروژه را روی هاست آپلود کنید (FTP/SFTP یا Git).
2. یک **دیتابیس MySQL** برای سایت مشتری بسازید.
3. فایل `.env.example` را به `.env` کپی کنید.
4. در `.env` تنظیمات دیتابیس را وارد کنید:
   ```
   DB_HOST=127.0.0.1
   DB_DATABASE=نام_دیتابیس_مشتری
   DB_USERNAME=کاربر_دیتابیس
   DB_PASSWORD=رمز_دیتابیس
   PLATFORM_URL=https://آدرس-پلتفرم-شما.com
   APP_URL=https://دامنه-سایت-مشتری.com
   ```

### ۳.۳ اجرای دستورات (SSH)
```bash
cd /path/to/customer-site
composer install --no-dev --optimize-autoloader
php artisan key:generate
php artisan migrate --force
php artisan storage:link
```

## مرحله ۴: نصب از طریق مرورگر

1. به آدرس سایت مشتری بروید (مثلاً `https://shop.example.ir`).
2. اگر `installed.lock` وجود نداشته باشد، ویزارد نصب (`/install`) نمایش داده می‌شود.
3. مراحل ویزارد:
   - **دیتابیس:** اگر در `.env` تنظیم شده، ممکن است رد شود.
   - **حساب مدیر:** نام، موبایل، ایمیل و رمز عبور ادمین را وارد کنید.
   - **تنظیمات:** نام سایت و تم را انتخاب کنید.
4. پس از اتمام، فایل `storage/installed.lock` ایجاد می‌شود.

---

## مرحله ۵: فعال‌سازی لایسنس (توسط مشتری یا شما)

1. وارد پنل ادمین سایت مشتری شوید: `https://دامنه-مشتری.com/login`
2. با موبایل و رمز عبور ادمین وارد شوید.
3. **مسیر:** ادمین → لایسنس
4. کلید لایسنس و دامنه را وارد کنید و «فعال‌سازی لایسنس» را بزنید.
5. در صورت موفقیت، ماژول‌ها و تاریخ پشتیبانی از پلتفرم دریافت و ذخیره می‌شوند.

| مشتری در پلتفرم ثبت شده | مشتری‌ها → افزودن |

| لایسنس در پنل سایت مشتری فعال شده | ادمین → لایسنس |

## نکات مهم

- **PLATFORM_URL:** سایت مشتری باید به API پلتفرم دسترسی داشته باشد. اگر پلتفرم روی دامنهٔ دیگری است، مطمئن شوید CORS و فایروال اجازهٔ درخواست را می‌دهند.
- **دامنه لایسنس:** اگر هنگام صدور لایسنس دامنه وارد کرده‌اید، دامنهٔ واقعی سایت مشتری باید دقیقاً همان باشد (بدون www یا با www بسته به تنظیم).
- **بروزرسانی:** مشتری فقط در دورهٔ فعال پشتیبانی می‌تواند بروزرسانی دریافت کند. از پنل پلتفرم → سایت‌ها → ویرایش سایت، تاریخ انقضای پشتیبانی را مدیریت کنید.
