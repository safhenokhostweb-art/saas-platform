# راهنمای بخش ۷: Module Marketplace و تحویل ماژول

## هدف

ماژول‌ها به‌عنوان محصول (نوع `module_addon`) در فروشگاه قابل خرید و پس از پرداخت به سایت انتخاب‌شده الحاق شوند.

## وضعیت (بخش ۲)

- محصول با نوع **module_addon** و **module_id** در پلتفرم تعریف می‌شود.
- مشتری در فروشگاه سایت را انتخاب می‌کند؛ پس از پرداخت در `OrderFulfillmentService::fulfillModuleAddon()` ماژول با `syncWithoutDetaching` به سایت الحاق می‌شود.
- customer-site با API تنظیمات یا اعتبارسنجی مجدد لایسنس لیست به‌روز ماژول‌ها را می‌گیرد.

## تکمیل‌های پیشنهادی ✓

- در فروشگاه برای محصول نوع ماژول، نام و توضیح ماژول نمایش داده شود. ✓
- در جدول modules فیلدهای `price_irr` و `version` در صورت نیاز اضافه شوند. (اختیاری)
