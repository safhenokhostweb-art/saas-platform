# راهنمای بخش ۵: Config/API ماژول‌ها برای customer-site

## هدف

customer-site بتواند تنظیمات سایت (نام، ماژول‌های فعال، انقضای پشتیبانی) را از پلتفرم بگیرد.

## ۱. API (پلتفرم)

- **روت:** `GET /api/site-config?license_key=...&domain=...`
- **پاسخ:** `allowed`, `site_title`, `modules`, `support_expires_at` (همان خروجی اعتبارسنجی لایسنس).
- **محدودیت:** `throttle:60,1`.

## ۲. استفاده در customer-site

- در فعال‌سازی لایسنس (بخش ۱) همین داده‌ها از پاسخ validate ذخیره می‌شود.
- برای همگام‌سازی دوره‌ای: Cron یا دکمهٔ «بروزرسانی از پلتفرم» که این API را صدا بزند و رکورد لایسنس محلی را به‌روز کند.
- منطق فعال بودن ماژول در customer-site بر اساس آرایهٔ `modules` دریافتی از پلتفرم باشد.
