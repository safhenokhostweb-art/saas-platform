# Business-to-Template Flow

1. Select one of five business profiles.
2. Validate its industry, audience, style, theme, and required sections.
3. Analyze the generic template's missing visual roles.
4. Rank only existing canonical Asset IDs.
5. Reject anything not active, platform-owned Master, theme-ready, and AI-ready.
6. Apply the existing section/position/responsive/theme contract.
7. Compare generic sections with accepted recommendations.
8. show score evidence and validation gates.

Recommendation visibility is not a license or deployment grant.
