# Simulation Architecture

```text
Business Scenario + Generic Template
              ↓
 Existing Smart Enhancement Engine
              ↓
 active/master/platform/theme-ready/AI-ready gate
              ↓
 Existing Placement Contract Validator
              ↓
 Before/After plan + score + brand-token simulation
              ↓
 Read-only Persian browser view
```

Node builds deterministic JSON. The browser never performs recommendation logic; it renders validated results and sanitized preview SVGs. AI controls are an inert local proposal interface.
