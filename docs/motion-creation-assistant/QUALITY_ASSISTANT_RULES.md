# Quality Assistant Rules

- Typography: minimum readable sizes, bounded line length, direction/language consistency, glyph coverage.
- Layout: title/action safe area, logical RTL alignment, mobile stacking, responsive aspect ratio.
- Animation: minimum readable holds, bounded simultaneous motion, meaningful transitions, reduced-motion fallback.
- Color: canonical brand tokens, contrast checks, accessibility.
- Performance: bounded asset bytes, SVG nodes, animation/layer count, concurrent effects.

Warnings guide improvement. Blockers prevent approval proposals but never mutate work automatically.
