# Persian / Arabic / English Typography Engine

Future font ingestion accepts private uploads only after signature, MIME, size, decompression, license, metadata, glyph, shaping, and complexity checks. TTF/OTF should normally be subset and converted to WOFF2; raw fonts are never sent to providers or exposed publicly without authorization.

Analysis reports Persian, Arabic, Latin, numerals, Arabic shaping, RTL behavior, mixed-script punctuation, estimated web weight, and conversion recommendation. The playground uses a deterministic mock—no upload conversion occurs.
