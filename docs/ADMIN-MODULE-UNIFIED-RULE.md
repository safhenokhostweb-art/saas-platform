# قانون واحد ماژول‌های ادمین (Admin Module Golden Rule)

این سند «قانون یکتا» برای همه ماژول‌های پنل ادمین است. هر ماژول جدید یا هر به‌روزرسانی باید دقیقاً با همین استاندارد اجرا شود تا تجربه کاربری، سرعت و نگهداری سیستم پایدار بماند.

## 1) ساختار اجباری هر ماژول

هر صفحه ماژول باید این 5 بخش را داشته باشد:

1. `Page Title` شفاف و ثابت (مثال: «مدیریت ماژول‌ها | پنل مدیریت»).
2. `Guide Box` کوتاه با توضیح کارکرد، ریسک‌ها و اثر تغییرات.
3. `KPI Summary` حداقل 3 شاخص کلیدی در بالای صفحه.
4. `Quick Filters` (جست‌وجو + فیلتر نوع/وضعیت) با اجرای سمت کلاینت برای پاسخ سریع.
5. `Action Zone` برای عملیات اصلی (ایجاد، ویرایش، تغییر گروهی، خروجی گرفتن).

## 2) UX و کاربرپسندی (الزامی)

- متن‌ها ساده، عملیاتی و بدون ابهام باشند.
- خطاها و پیام موفقیت، واضح و نزدیک به محل اقدام نمایش داده شوند.
- دکمه‌های مهم با `confirm` مناسب محافظت شوند (برای عملیات پرریسک).
- صفحه روی موبایل/تبلت/دسکتاپ قابل استفاده باشد (Responsive).
- جدول‌ها برای دیتاهای زیاد `overflow-x-auto` داشته باشند.

## 3) عملکرد و سرعت (الزامی)

- جست‌وجو/فیلترهای پرتکرار تا حد ممکن `client-side` باشند.
- از `N+1` در کوئری‌ها جلوگیری شود.
- فقط داده موردنیاز لود شود (حداقل ستون‌ها).
- برای فهرست‌های سنگین از صفحه‌بندی یا lazy loading استفاده شود.
- اسکریپت‌های صفحه سبک و بدون وابستگی اضافی باشند.

## 4) SEO و ایندکس‌گذاری

- صفحات ادمین همیشه `noindex, nofollow` بمانند.
- عنوان صفحه (`title`) باید یکتا و معنی‌دار باشد.
- لینک‌ها و مسیرها باید خوانا و سازگار با route nameها باشند.

## 5) دسترس‌پذیری و کیفیت

- ورودی‌ها `label` واقعی داشته باشند.
- دکمه‌ها و عناصر تعاملی `aria` مناسب داشته باشند.
- کنتراست رنگ وضعیت‌ها (success/warning/error/info) حفظ شود.
- میانبرهای مهم با کیبورد قابل استفاده باشند.

## 6) امنیت و پایداری

- تمام فرم‌ها دارای CSRF باشند.
- اعتبارسنجی سمت سرور برای همه ورودی‌ها الزامی است.
- تغییرات حساس داخل تراکنش (`DB::transaction`) انجام شود.
- تغییرات غیرقابل بازگشت فقط با هشدار صریح انجام شوند.

## 7) تعریف Done برای هر ماژول

به‌روزرسانی ماژول زمانی کامل است که:

- [ ] استاندارد 5 بخشی ساختار صفحه رعایت شده باشد.
- [ ] فیلتر/جست‌وجوی سریع عملیاتی باشد.
- [ ] عملیات اصلی ماژول قابل انجام باشد و پیام مناسب بدهد.
- [ ] تست دستی UI روی موبایل و دسکتاپ انجام شده باشد.
- [ ] هیچ رگرسیون در مسیرهای فعلی ایجاد نشده باشد.

---

نسخه اولیه این قانون از ماژول `admin.modules.index` شروع شده و برای تمام ماژول‌های ادمین مرجع اجرایی است.
