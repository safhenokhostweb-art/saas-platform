# CRM — Admin Guide

## داشبورد (`/admin/crm/{siteId}`)

آمار لحظه‌ای: سرنخ‌های باز، مشتریان، معاملات باز، ارزش خط لوله، معاملات موفق/ناموفق، وظایف امروز، آخرین فعالیت‌ها.

## Sales Kanban (`/admin/crm/{siteId}/opportunities/kanban`)

هر ستون یک مرحله از خط لوله انتخاب‌شده است. معامله را با درگ‌اند‌دراپ به ستون دیگر ببرید — بدون رفرش صفحه ذخیره می‌شود، تاریخ تغییر مرحله ثبت می‌شود، و یک Activity خودکار («تغییر مرحله معامله») روی همان معامله ثبت می‌گردد. انتقال به مرحله نوع «برد»/«باخت» به‌صورت خودکار وضعیت معامله را می‌بندد.

## گزارش فروش (`/admin/crm/{siteId}/reports`)

- **Win Rate / Lost Rate**: نسبت معاملات برد/باخت به کل معاملات بسته‌شده.
- **Conversion Rate**: نسبت سرنخ‌های تبدیل‌شده به کل سرنخ‌ها.
- **Revenue Forecast**: مجموع مبلغ معاملات باز، وزن‌دهی‌شده با احتمال هر مرحله.
- **Sales by Stage / Period**: توزیع فعلی معاملات باز به تفکیک مرحله، و روند درآمد برد در ۶ ماه اخیر.
- دکمه «خروجی CSV» گزارش را دانلود می‌کند.

## Import / Export

- **Import**: از صفحه Contacts/Companies/Leads روی «Import CSV» کلیک کنید → فایل را آپلود کنید → یک صفحه پیش‌نمایش نشان می‌دهد کدام ردیف معتبر/تکراری/نامعتبر است → «تأیید Import» فقط ردیف‌های معتبر را وارد می‌کند.
  - ستون‌های مورد نیاز هر Entity در همان صفحه نمایش داده می‌شود.
  - تشخیص تکراری: بر اساس ایمیل (Contact/Lead) یا نام (Company).
- **Export**: از صفحات Contacts/Opportunities/Reports روی «Export CSV» کلیک کنید.

## یادآوری خودکار (Task Reminder)

هر ساعت، سیستم به‌صورت خودکار موارد زیر را بررسی و اطلاع‌رسانی می‌کند (یک‌بار برای هر مورد، بدون تکرار):
- وظایفی که به سررسید نزدیک شده‌اند.
- وظایفی که از سررسید گذشته‌اند.
- معاملات بازی که ۱۴ روز بدون هیچ فعالیتی مانده‌اند.

اطلاع‌رسانی هم به‌صورت اعلان داخل پنل و هم پیامک (در صورت فعال بودن) برای مدیر سایت ارسال می‌شود.
